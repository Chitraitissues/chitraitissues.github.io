# CHITRAI TISSUES — Website (GitHub Pages)

This repository contains a simple, responsive one-page website and two policy pages for CHITRAI TISSUES. Upload these files to a GitHub repository and enable GitHub Pages to publish the site.

Files included:
- index.html
- styles.css
- privacy.html
- terms.html
- images/ (folder) — add the following images:
  - images/logo.png  ← Save the logo you uploaded (Image 1) with this filename
  - images/hero-placeholder.jpg  ← optional hero image
  - images/product-1.jpg
  - images/product-2.jpg
  - images/product-3.jpg

Deployment (GitHub Pages - user/site recommended)
1. Create a new public GitHub repository named exactly: `Chitraitissues.github.io`
2. On your local machine:
   - git init
   - git add .
   - git commit -m "Initial CHITRAI TISSUES site"
   - git branch -M main
   - git remote add origin https://github.com/Chitraitissues/Chitraitissues.github.io.git
   - git push -u origin main
3. Wait a minute and open: https://Chitraitissues.github.io

If you use a different repo name:
- Push the files to that repo. In the repository Settings → Pages set Source to branch `main` and folder `/ (root)`. The site will be available at https://<your-username>.github.io/<repo-name>
